# I ported RobTop's Forlorn to Android! (tested on Android 7 \& 12)

Remember Forlorn, the little iOS 7 game RobTop made? It now runs on Android.

All 5 levels are playable. I've been playing it on my old Moto G4 Play (Android 7), and it runs on Android 12 as well.

## Builds

* **Android 5, 6 and 7:** ARMv7 (32-bit)
* **Android 8 and newer:** ARM64

I've only tested Android 7 and 12.

The rest should work since they use the same builds, but I can't promise it.

## Testing

No emulator here, everything is on real devices: first install and launch, the first level with a quick look at the features (tested on M5s), and raw gameplay filmed with a second phone (Poco M5s) while I played on the Moto.

Unofficial fan-made port. All assets and IP belong to Robert Topala AKA (RobTop), Daniel Bengtsson \& Niklas Dennerståhl.
